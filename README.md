# Git Intro

## Description

Ce repository contient mes premiers pas avec Git et GitHub.
J'ai appris à utiliser les commandes de base de Git, à travailler avec des branches et à faire des pull requests.

---

## Compétences acquises

- Initialiser un repo et faire des commits
- Créer et fusionner des branches (`merge`, `pull request`)
- Travailler avec des fichiers texte versionnés

---

## Fichiers

| Fichier | Description |
|---|---|
| `greeting.txt` | Créé dans une branche `feature-greeting` |
| `improvement.txt` | Créé dans une branche `feature-improvement` |
| `message.txt` | Modifié directement sur `main` |
